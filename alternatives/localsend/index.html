Comparison

Flow vs LocalSend.

Both are free, open, local-first ways to move files between your devices. The difference is scope: LocalSend is an excellent file transfer tool; Flow aims at the whole continuity experience around the transfer.

Where LocalSend is stronger today

  • Native iOS app. LocalSend has a real iPhone/iPad app in the App Store; Flow's iOS story is Safari-based for now.
  • Maturity. It's been around longer, has more users, and is in app stores — installs carry no warnings.
  • Linux support. LocalSend covers Linux natively; Flow doesn't yet.

Where Flow goes further

  • Continuity, not just transfer. Clipboard sync, screen sharing, extended display and input linking — the AirDrop + Universal Clipboard + Universal Control bundle, not only the file part.
  • Always-available agent. Menu bar / tray presence means the device stays discoverable and receivable without anyone opening an app.
  • Resumable, queueable sends to multiple recipients at once — transfers survive disconnects and reconnects.
If you only need to move files — especially to iOS or Linux — LocalSend is a solid, proven choice. If you want your devices to feel like one system, that's what Flow is built for.
