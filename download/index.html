Install — and the one warning you'll see

Run the installer for your OS

Windows: run the .exe. Mac: open the .dmg and drag Flow to Applications. Android: open the APK and allow your browser's install permission.

Get past the "unknown developer" warning

Flow is an unsigned early-alpha build, so every OS shows its standard caution once. Windows: More info → Run anyway. Mac: right-click Flow → Open → Open. Android: More details → Install anyway.

Keep it in the tray / menu bar

Flow lives in the menu bar on Mac and the system tray on Windows — discovery and sharing keep working with no window open. That's the whole point.

Join the same Wi-Fi and pair

Devices on the same network find each other automatically. Tap Connect on one side, Allow on the other — done. See how pairing works.

No Wi-Fi router between your devices? Turn on a phone hotspot and join both — discovery works identically. Different networks entirely? Invitation links or a self-hosted relay bridge them — details in Help.
