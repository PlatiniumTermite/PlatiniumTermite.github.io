Use case

A Mac and a PC, acting like one machine.

Apple's Continuity stops at the Apple logo — Flow carries the same experience across the OS border. Both directions, all four continuities.

The four continuities you get

Files, AirDrop-style

Mac↔PC appears in Nearby automatically. Tap, approve, drag — folders, resume, multi-send, lands in Downloads.

One clipboard

Copy on the Mac, paste in Windows — text and images, instantly, both directions. No send action at all.

Screens & displays

View the other computer's screen after approval — or extend the Mac's desktop onto the PC as a second display (experimental).

One keyboard & mouse

Drive the PC from the Mac's keyboard or vice versa — approval- gated, heartbeat-supervised, Escape to release.

Setup — under two minutes

Install on both computers

DMG on the Mac (drag to Applications), .exe on Windows. Each OS warns once — right-click → Open on Mac, More info → Run anyway on Windows.

Same Wi-Fi, both running

Flow sits in the Mac menu bar and Windows tray — no window needs to stay open for the computers to see each other.

Connect → Allow

Either side can initiate; the other approves. From then on, everything — files, clipboard, screens, input — is one tap away.

Worth knowing

  • Extended display is experimental. Mac→PC works; the Windows side may need a virtual-display driver for wireless second-screen use.
  • Input linking is powerful. It needs its own setting enabled plus per-session approval — treat it like handing over your keyboard, because it is.
  • Rejoining restores state. If one computer sleeps or drops off Wi-Fi, the clipboard replays and queued sends deliver when it returns.
