# Flow — AirDrop-style sharing for Windows, Mac & Android

**[Download Flow →](https://platiniumtermite.github.io)**

Flow is a free, open alternative to AirDrop, LocalSend, KDE Connect, Snapdrop and AirDroid — giving every device you own the continuity features Apple keeps inside its own ecosystem:

- **AirDrop-style file sharing** — auto-discovery on Wi-Fi, approval pairing, files/folders/text/links both ways with resume
- **Universal clipboard sync** — copied text and images move instantly between desktops
- **Screen sharing** — view another computer's screen after approval
- **Extended display** — a second computer as an extra monitor over Wi-Fi (experimental)
- **Keyboard & mouse link** — bidirectional, approval-gated, like Universal Control
- **Menu-bar / tray agent** — works without keeping a window open

Devices find each other over local Wi-Fi via mDNS and transfer peer-to-peer over WebRTC. iPhone/iPad join via Safari. No accounts, no cloud relay required.
