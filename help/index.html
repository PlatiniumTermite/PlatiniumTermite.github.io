Install warnings — what to click

PlatformWarningFix
Windows "Windows protected your PC" (SmartScreen) More info → Run anyway
Windows Browser blocked the .exe download Keep in the downloads bar
Windows Firewall prompt on first launch Allow on private networks
Mac "Flow can't be opened…" / "unidentified developer" Right-click Flow → Open → Open
Mac "Flow is damaged" Same fix — right-click → Open → Open
Android Play Protect warning More details → Install anyway
Android "Install unknown apps" blocked Allow it for your browser once, then install

Why the warnings exist: Flow is an unsigned alpha distributed outside the app stores. Signed builds are planned; the warnings are expected, not malware.

Devices can't see each other

Same Wi-Fi on both — really

Guest networks and "AP isolation" block discovery. Check the network name matches; if your router isolates clients, use the hotspot path below.

Flow is actually running

The window can be closed — but the menu-bar (Mac) or tray (Windows) icon must be there, and on Android the app must be open or recently used.

Try the instant fallback: hotspot

Turn on a phone's Personal Hotspot, join both devices to it — it's a normal LAN, so discovery and transfers work exactly like shared Wi-Fi.

Different networks entirely

Use an invitation link / QR where the connection address is reachable, or point Flow at a self-hosted wss:// relay (Settings → Connection details).

Feature-specific notes

  • Android clipboard — Android blocks background clipboard reads for every third-party app. Flow syncs instantly while the app is open and captures via the notification-tap path otherwise.
  • iPhone / iPad — join via Safari (QR or link). Clipboard-in-browser works; share-sheet and background sync need the native iOS app, which is planned.
  • Extended display — experimental. Mac→computer is supported; Windows receivers may need a virtual-display driver for wireless second-screen use.
  • Keyboard/mouse link — needs its setting enabled on the receiving computer and a per-session approval. Escape releases instantly; lock, sleep and revocation all tear it down.
  • Where do files land? — your Downloads folder, with automatic collision renaming.
