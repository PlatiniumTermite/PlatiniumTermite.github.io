Security & privacy

Local-first. Approval-gated. No accounts.

Flow is designed so your files never leave your devices — there's no cloud to upload to, and nothing happens without someone pressing Allow.

What protects you

Explicit approval, always

Pairing, screen sharing, extended display and keyboard/mouse control each require someone on the receiving device to press Allow. There is no silent connect path — including from devices you've used before.

Encrypted, device-to-device

Transfers ride WebRTC data channels, which are encrypted end-to-end by the transport itself (DTLS). Content moves directly between your devices — it doesn't transit a Flow server.

No accounts, no uploads

There's no Flow account, no email, no cloud inbox. Your files, clipboard and screens stay on your network — discovery is local mDNS, and payloads go peer-to-peer.

Scoped control

Keyboard/mouse linking needs its own opt-in setting and per-session approval, sends heartbeats, and tears down on Escape, lock, sleep, revocation or disconnect.

Friend sessions are isolated

Sharing with someone else's device uses a separate friend space — your personal devices and clipboard are never included, and the session is meant to be ended when done.

Verifiable builds

Every release ships a SHA256SUMS.txt so you can verify the file you downloaded is the file that was built. Source code is public on GitHub.

What leaves your device — and what doesn't

DataWhere it goes
Files, folders, clipboard, screens, input events Device-to-device only — encrypted WebRTC, never a Flow server
Device name & presence mDNS broadcast on your local network; signaling to the Flow instance you connect to (your own device or a relay you choose)
Accounts, analytics, telemetry None — there is no Flow account system and no usage telemetry in the app
Update checks (Windows) Reads the release feed on GitHub when you press "Check for updates" or on launch

Honest caveats — early alpha

  • Unsigned builds. Installers aren't yet code-signed or notarized, so OSes show standard unknown-developer warnings. Verify checksums if you want extra assurance.
  • Alpha software. It has an automated test suite and packaged smoke tests, but hasn't been through a formal security audit. Don't use it for highly sensitive data yet.
  • Same-network trust. mDNS discovery trusts the local network — approval prompts are the line that keeps strangers out. Only approve devices you recognize, exactly like AirDrop.
  • Screen & input features are powerful. They're approval-gated and revoke cleanly, but treat them like handing someone your keyboard — because functionally, you are.

Report a security issue

Found something? Please report it privately by opening an issue on the source repository marked as a security concern — don't post exploit details publicly first.
